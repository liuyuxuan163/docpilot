# IT 常见问题与自助排查

## VPN 连不上怎么办

按以下顺序排查：

1. **确认 MFA 是否正常**：动态口令有 30 秒有效期，若刚跨过时间窗请等待下一个口令。
2. **检查本机时间是否准确**：时间偏差超过 60 秒会导致 MFA 校验失败。
   开启系统自动同步时间后重试。
3. **切换网络**：部分公共网络会封锁 VPN 端口。可尝试用手机热点验证。
4. **重启 VPN 客户端**：完全退出（不是最小化）后重新启动。
5. **清除 DNS 缓存**：Windows 执行 `ipconfig /flushdns`；macOS 执行
   `sudo dscacheutil -flushcache`。

以上都无效时，提交 IT 工单并附上**客户端日志**（路径：设置 → 高级 → 导出日志）。

## 密码忘记或账号被锁定

- **密码遗忘**：在 SSO 登录页点击「忘记密码」，通过企业邮箱重置。
- **账号锁定**：连续输错 5 次密码会锁定 30 分钟；急用可通过 IT 服务台人工解锁。
- **MFA 设备丢失**：需本人携带工牌到 IT 服务台重置，**不接受线上申请**（防冒用）。

## 邮箱收不到外部邮件

1. 检查「垃圾邮件」文件夹
2. 确认发件人是否在**黑名单**（设置 → 反垃圾 → 黑名单）
3. 若为特定域名全部收不到，提交工单请 IT 检查网关策略

## 打印机无法连接

- 确认连接的是 `OFFICE-PRINT` 无线网络（不是访客网络）
- 驱动下载地址：内网 `http://intranet.it/printers`
- 若提示"无法找到打印机"，先确认机器是否处于休眠状态，按一下面板唤醒

## 软件安装申请

公司设备安装软件需走申请流程：

| 软件类型 | 审批人 | 时长 |
|---|---|---|
| 办公类（如 PDF 工具） | 直属主管 | 1 个工作日 |
| 开发工具（IDE、数据库客户端） | 直属主管 + IT | 1 个工作日 |
| 涉及网络代理/抓包类工具 | IT 安全负责人 | 3 个工作日 |
| 未授权远程控制类软件 | **一律不批** | — |

## 工单提交规范

提交 IT 工单时请包含：

1. **现象**：具体报错信息（截图或文字）
2. **影响范围**：只有你一个人，还是整个团队
3. **发生时间**：尽量精确到分钟
4. **已尝试的操作**：避免 IT 重复你已做过的步骤
5. **紧急程度**：阻塞工作 / 影响效率 / 可以等

**紧急程度说明**：只有"完全无法工作且无替代方案"才选"阻塞"。
选错紧急程度会降低你在工单队列中的可信度。

## 服务台联系方式

- 工单系统：内网 `http://intranet.it/ticket`（推荐，可跟踪进度）
- 服务台电话：分机 8888（工作日 9:00-18:00）
- 紧急故障（生产环境）：安全热线，7×24 小时

## 常见问题

**Q：能申请管理员权限吗？**
A：普通员工不授予本机管理员权限。确需管理员权限的开发场景，可申请
"受限提权"，权限按次生效（每次 2 小时），且操作会被审计。

**Q：公司电脑能装个人软件吗？**
A：不可以。个人软件可能带来安全风险，需通过软件安装申请流程评估。
